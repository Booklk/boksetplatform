# Jdawil Mobile App Template

Capacitor wrapper that turns a Jdawil vendor's storefront into a real
native mobile app on Google Play and the App Store.

**How it works:**

```
[vendor's PWA]                    [native shell]
https://jdawil.sa/store/<slug> ←  wrapped in
                                  Capacitor (Android + iOS)
                                  + splash + icons + push + haptics
                                  + native share sheet
```

The shell loads the vendor's storefront inside a `WKWebView` (iOS) /
`WebView` (Android). To the customer, it's a real native app. To us,
it stays in sync with whatever we ship to the storefront — no app
re-build needed for content changes.

## Generated by `services/mobileAppBuilder.ts`

You don't edit this template directly per vendor. The build orchestrator:

1. Copies this template to a temp folder.
2. Replaces placeholders (`{{APP_NAME}}`, `{{APP_BUNDLE_ID}}`,
   `{{VENDOR_STORE_URL}}`, `{{PRIMARY_COLOR}}`, `{{VENDOR_HOST}}`,
   `{{KEYSTORE_ALIAS}}`) with the vendor's values.
3. Drops the vendor's 1024×1024 logo into `resources/logo.png` and the
   splash into `resources/splash.png`.
4. Runs `npm install`, `npm run sync:android`, then `@capacitor/assets`.
5. Builds `app-release.apk` via `./gradlew assembleRelease`.
6. Uploads APK to S3 + attaches URL to the order row.

## Manual final step (one-time per vendor)

For **Google Play**:
- Vendor creates a Play Console account ($25 one-time).
- Uploads the APK + screenshots + description.
- Review usually 1-3 days.

For **App Store**:
- Apple requires an Apple Developer account ($99/year).
- Build the IPA on macOS via Xcode (or use EAS Build cloud).
- Submit via App Store Connect.
- Review usually 1-7 days. Apple may ask for clarification — concierge
  service handles this for the vendor.

## Test locally

```bash
# Replace placeholders manually for a quick test:
sed -i 's/{{APP_NAME}}/Test Store/g; s/{{APP_BUNDLE_ID}}/sa.jdawil.test/g; \
       s|{{VENDOR_STORE_URL}}|https://jdawil.sa/store/test|g; \
       s/{{PRIMARY_COLOR}}/#1e3a8a/g; s/{{VENDOR_HOST}}/jdawil.sa/g; \
       s/{{KEYSTORE_ALIAS}}/test/g' \
  capacitor.config.json index.html src/main.ts package.json

npm install
npm run sync:android
npx cap open android   # opens in Android Studio
```
